# Тишь: демо-сайт кабинета косметологии

Пример одностраничного сайта с онлайн-записью для косметологов и салонов красоты.
Кабинет «Тишь», специалист, адрес и цены вымышлены.

- Онлайн-запись только имитирует отправку: данные не уходят с устройства и нигде не сохраняются.
- Есть галочка согласия на обработку ПДн, шаблоны согласия (`soglasie.html`) и политики (`politika.html`).
- Безопасность: Content Security Policy (скрипты только с этого сайта, без внешних запросов), `noindex`, без сторонних трекеров.

Дизайн и разработка: qwedesign, Telegram @qweqwasdd
